# 하늘왕국 온라인 — 친구들과 하는 3D 멀티플레이 프로토타입

## 실행 전 알아둘 점
이 프로젝트는 실제 친구가 접속할 수 있는 **서버 기반** 프로토타입입니다. `index.html`을 파일 앱에서 직접 여는 방식(`file://`)으로는 동작하지 않습니다. Node.js 서버를 실행하거나 인터넷에 배포한 뒤 그 서버 URL로 접속해야 합니다. Three.js는 CDN에서 로드되므로 인터넷이 필요합니다.

## 로컬 실행
Node.js 18 이상 설치 후 프로젝트 폴더에서:

```bash
npm install
ADMIN_PASSWORD='Sikuadmin123' npm start
```

브라우저에서 `http://localhost:3000` 접속. 같은 Wi-Fi의 친구는 호스트 PC의 로컬 IP 주소와 `:3000` 포트로 접속할 수 있습니다. 인터넷 너머 친구와 플레이하려면 HTTPS/WSS를 지원하는 Node.js 호스팅에 배포하세요.

## 포함된 기능
- 닉네임 입력 후 입장, Three.js 3D 아레나, 모바일 가상 조이스틱/공격 및 PC WASD
- 실시간 위치, HP, 레벨, 돈, 채팅
- 게임 내 관리자 버튼과 비밀번호 로그인 (`Sikuadmin123`, 서버에서 확인)
- 관리자 배지, 플레이어 목록/검색, 킥, 이름 기반 밴/언밴, 아이템 지급/회수, 돈/레벨 설정
- 서버 잠금/해제, 전체 아이템 지급, 전체 화면 공지 애니메이션
- 관리자 전용 아이템 표시 및 관리자 스킬 아이템 생성
- 친구 추가(현재 온라인 세션의 친구 목록에 추가)

## 중요한 제한
이것은 기능 확장을 위한 프로토타입이며 정식 상용 게임 수준으로 검증된 제품이 아닙니다. 현재 밴/인벤토리/돈/레벨/친구 데이터는 서버 재시작 후 영구 보존되지 않습니다. 인증 계정, 영구 DB, 거래 시스템, 실제 영구 밴 저장, 계정별 개발자 등록, TLS 설정, 속도 제한/악용 방지, 감사 로그, 자동화 테스트는 별도 작업이 필요합니다. 비밀번호는 브라우저 코드에 포함하지 않고 서버에서 확인하지만, 공개 배포 전에는 호스팅 환경변수 `ADMIN_PASSWORD`로 변경하고 HTTPS를 사용하세요. 관리자 권한은 로그인한 현재 세션에 부여됩니다.


화뢰신 강화 연출: 젠이츠풍 자세 낮추기/검 휘두르기 모션, 백색 검광 아크, 짧은 타격 정지 연출을 추가했습니다. 사운드는 Web Audio 합성으로 충전·검격·천둥 충격음을 재생하며 첫 사용자 입력 이후 브라우저 오디오 정책에 따라 활성화됩니다. 커스텀 캐릭터 모델이나 상용 녹음 음원은 포함되지 않습니다.
